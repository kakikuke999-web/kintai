# シフト → カレンダー登録

月初に配られるシフト表の写真から自分の行だけを読み取り、カレンダー用の .ics ファイルを作るWebアプリです。前日夜と当日の通知が付きます。

## 使い方
1. 名前・対象月を確認する（シフト記号の時間は「シフト記号と時間」で編集できます）
2. シフト表の写真を選ぶ
3. 自分の行の「1日」のマスと「末日」のマスをタップする（＋で拡大。写真が逆さまでも大丈夫）
4. 青い枠がマスに重なっていることを確認して「読み取る」を押す
5. 黄色の行を中心に、写真の切り抜きと見比べて記号を直す（特別な勤務時間は「他」を選んで時間を入力）
6. 「.icsをダウンロード」→ カレンダーに取り込む

## スマホで使うには
HTMLファイルなので、どこかに置いてスマホのブラウザで開きます。おすすめは GitHub Pages です。
`index.html` と `manifest.webmanifest` を公開リポジトリに置き、Settings → Pages を有効にします。
ホーム画面に追加すると、アプリのように開けます。

## 仕様メモ
- OCR は tesseract.js（端末内で処理するので無料。初回だけ認識データを数MBダウンロードします）
- 英字は単語モードで読み、英字と読めなかったマスは文字の高さで「*」と「休・有」に振り分けます
- 休・有・* の日は登録しません
- iPhone の標準カレンダーは .ics の通知（VALARM）をそのまま使えます。Google カレンダーは取り込み時に通知を捨てるので、
  「Googleカレンダー用」にチェックして通知用の予定を別に作り、専用カレンダーのデフォルト通知を「0分前」にしてください
- 入力内容は端末のブラウザ（localStorage）に月ごとに保存されます
